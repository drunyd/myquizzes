# MyQuizzes Repository

## Overview

This repository contains a collection of quiz content organized by subject and version. It uses the **pi** coding agent framework and includes automated workflows for generating quizzes from work-in-progress materials.

The project is structured to support:
- **Content creation**: Write quiz questions in Hungarian in the `wip/` folder
- **Automated generation**: Convert WIP content into structured YAML quizzes and HTML wiki pages
- **Versioned organization**: Separate folders for different quiz versions (6.o and 7.o)
- **Subject-based categorization**: Organized by subject areas (maja, mate)

## Available Skills & Workflows

### Core Skill: `generate-quiz-from-wip`

This project includes a specialized **pi agent skill** that automates quiz generation:

**Location**: `/home/dru/projects/myquizzes/repo/.pi/skills/generate_quiz_from_wip/SKILL.md`

**What it does**:
- Processes PDF or text files in the `wip/` folder
- Reads content and generates 50-question YAML quiz files
- Supports multiple question types: singlechoice, multichoice, word, and ordering
- All questions are in Hungarian
- Creates separate YAML files for each subject in the appropriate version folder (6.o/<subject>/ or 7.o/<subject>/)
- Generates themed HTML wiki pages from the same source material
- Stores the wiki page path in the quiz's `Source:` attribute

**How to use**:
```bash
# The skill runs automatically when you:
# 1. Add new content to wip/
# 2. Use the skill to process the files
# 3. Results appear in the versioned subject folders and wiki directories
```
